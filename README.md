# DinaPro v9.0.2 - Ev Ekonomi Yönetimi

GitHub Pages ve WebApp (Ana Ekrana Ekle / PWA) uyumlu tam kaynak paketi.

## İçerik
- `index.html` — Ana sayfa (PWA & Apple WebApp meta etiketleri dahil)
- `style.css` — Tema ve arayüz stilleri
- `app.js` — Uygulama mantığı ve 7 katmanlı yerel hafıza
- `manifest.json` — WebApp / PWA tanım dosyası
- `apple-touch-icon.png` (180x180), `icon-192.png` (192x192), `icon-512.png` (512x512) — Uygulama logoları

## GitHub Pages Kurulumu
1. Tüm dosyaları GitHub deponuzun ana dizinine yükleyin.
2. **Settings → Pages → Branch: main / (root)** seçeneğini kaydedin.
3. Oluşan `https://kullaniciadiniz.github.io/depo-adi/` bağlantısını iPad/iPhone Safari veya Chrome ile açıp **Paylaş → Ana Ekrana Ekle** dediğinizde DinaPro logosuyla tam ekran WebApp olarak kurulur.
